# Nexleaf design skills

Claude skills used for ColdTrace design work. Each zip in `skills/` is one skill and can be uploaded in Claude under Settings > Capabilities > Skills.

`design-workflow-0.3.1.plugin` bundles the generic version of the workflow as a Claude plugin. Read `design-workflow-plugin-START-HERE.md` before installing it; it needs onboarding (ORG.md) to be useful.

Product knowledge: coldtrace-product-context
Design system rules: nexleaf-design-system, ds-components-only
End-to-end workflow: nexleaf-design-workflow, onboard-design-workflow
PRDs and tickets: prd-writer, one-page-prd-generator, prd-to-tickets, product-os
Figma and prototypes: figjam-decision-board, figma-design-audit, figma-pixel-perfect, figma-reference-registry, prototype-figma-parity, prototype-review-then-publish, screen-states-and-interactions, design-critique
